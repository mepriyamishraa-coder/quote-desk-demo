# Quote Desk — Sales & Order Tracking Dashboard

A single-page dashboard for an entrance-automation business (automatic doors, rolling shutters, boom barriers, glass partitions) that tracks every quotation from first offer to final handover.

**Live demo:** https://mepriyamishraa-coder.github.io/quote-desk-demo/

> All company names, clients, people and figures in this demo are fictional sample data.

## What it does

- **KPI summary:** total quoted value, open pipeline, follow-ups due, confirmed orders, pending installations, completed projects and overdue dispatches
- **Value by status:** click any status to filter the quote register
- **Month-by-month chart:** quoted value per month, stacked by current status
- **Conversion view:** win rate donut, won vs lost, and top products quoted
- **Follow-ups:** grouped into overdue, today and next 3 days
- **Quote register:** searchable and filterable table of all quotes
- **Quote detail drawer:** full commercial offer (basic value, freight, packing, installation, GST @ 18%) and the order journey from quote to handover

## Built with

- HTML, CSS and vanilla JavaScript (no frameworks)
- Charts drawn with CSS and inline SVG
- Indian number formatting (₹ Lakh / Crore)
- Responsive layout for desktop and mobile

## Run it locally

Download `index.html` and open it in any browser. No install or build step needed.
